# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for a security problem. Use GitHub's
[private vulnerability reporting](https://github.com/99Ayush/NIVORA/security/advisories/new)
so the report stays private until a fix is ready.

A useful report includes:

- the affected commit or version
- reproduction steps
- the impact you observed
- any suggested mitigation

I aim to acknowledge reports within 72 hours.

## Scope and expectations

Nivora is a demo platform with a static listing dataset and in-memory reviews. Do not deploy it with real student data without adding authentication on the API.

## Supported versions

The main branch is the supported version. Older commits are not patched.

# **App Name**: Nivora : Home away from Home

## Core Features:

- Homepage Search: Simple search interface with fields for college name and pincode.
- Listing Display: Show a list of PG, mess and flat options using the search details
- AI-Powered Recommendations Tool: Based on the college and pincode, the AI model finds a short summary of user sentiment and feedback from multiple sources.
- Interactive Map: Displays PG/mess/flat locations on a map within the specified area.
- Anonymous Review System: Any user can write a review after logging in to this website.
- Help Chatbot Integration: Integrate a chatbot for user support.

## Style Guidelines:

- Primary color: Deep earthy green (#414A37) for headings and important elements.
- Accent color: Warm brown (#99744A) for buttons and key accents.
- Background/Secondary color: Light sandy beige (#DBC2A6) for the main background and text boxes.
- Font: 'Inter' sans-serif for a clean, easy-to-read user experience.
- Clean, minimalist layout with a central search interface on the homepage.
- Use icons that suggest student life and welcoming spaces.
